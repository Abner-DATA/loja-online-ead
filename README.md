# Loja Online

Projeto de e-commerce desenvolvido na disciplina git, Agile & dev culture.

## Como rodar

git clone https://github.com/Abner-DATA/loja-online-ead.git
cd loja-online-ead
npm install
npm start

## Estrutura 

- /src - Codigo da aplicação
- / test - testes automatizados
- .github/workflows - pipeline de CI
